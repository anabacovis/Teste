Estados

Estados do sistema

Referência visual e de código para loading, vazio, erro e outros estados obrigatórios.

B3 — Bloqueador resolvido

Loading — Skeleton

Exibido enquanto dados carregam do Supabase. Nunca mostrar tela em branco.

AgenciaStates.skeleton(container, rows=5, cols=4) // tabela
AgenciaStates.skeletonCards(container, count=4) // cards
Skeleton — Tabela (Produção, Financeiro)
Skeleton — Cards (Hoje, Ana, Nicole)

Empty — Sem dados

Quando nenhum item corresponde ao filtro aplicado, ou quando a lista realmente está vazia.

AgenciaStates.empty(container, { title, desc, action, onAction })
Produção — Nenhuma entrega
Aprovações — Nenhuma aprovação pendente
Financeiro — Nenhuma cobrança
Arquivos — Nenhum link

Error — Falha de carregamento

Quando a query falha (rede, timeout, servidor). Sempre oferecer "Tentar novamente".

AgenciaStates.error(container, { msg, onRetry, details })
Erro de rede
Erro do servidor (500)

Sem permissão

Quando o usuário tenta acessar conteúdo que o papel (role) não autoriza.

AgenciaStates.noPermission(container, { msg })
Financeiro — sem permissão
Admin — usuário não-admin

Sem conexão

Quando o dispositivo perde a conexão com a internet.

AgenciaStates.offline(container)
Offline

Estados de botão

Para ações assíncronas — salvar, criar, marcar como pago, etc.

AgenciaStates.saving(btnEl) // desabilita + spinner
AgenciaStates.saved(btnEl, label) // verde + check
AgenciaStates.resetBtn(btnEl, label) // restaura

Clique nos botões para ver a sequência de estados.

Toast — Confirmações rápidas

Para confirmações não-críticas de ação. Aparece na base da tela por 2.2s.

AgenciaStates.toast('Mensagem aqui') // sucesso
AgenciaStates.toast('Erro ao salvar', 'error') // erro
